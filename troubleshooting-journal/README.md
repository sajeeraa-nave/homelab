# Troubleshooting Journal

A running log of every problem encountered while building this lab. The actual entries are in [`journal.md`](./journal.md).

Breaking things on purpose and working through them is the point. This journal is where that work gets recorded.

---

## Entry Format

Every entry follows the same structure:

```
### [YYYY-MM-DD] — Short title of the issue

**Lab:** Lab 1 / Lab 2 / Lab 3 / Lab 4 / Setup
**Severity:** Low / Medium / High

**Problem**
What went wrong, in one or two sentences.

**Symptoms**
The actual observable behavior. Error messages verbatim. Screenshots if relevant.

**Root Cause**
Why it actually happened — not the surface symptom. One level deeper.

**Fix**
The exact steps that resolved it. Specific enough to repeat.

**What I Learned**
The concept this reinforced.

**Prevention**
What would stop this from happening again.
```

---

Entries are added newest-first.
